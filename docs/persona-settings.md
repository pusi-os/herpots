# Персонаж HerPots: настройки и протокол

Дата: 2026-11-24. Что Hermes задаёт устройству сообщением `persona` — поля, диапазоны, где
хранится и как проверяется.

## Схема

Одна запись на профиль Hermes в `<hermes home>/plugin-data/herpots/persona.json`:

```json
{
  "default": {"outfit": 4, "background": 2, "banter": 1, "tempo": 100, "mini": true}
}
```

`plugin/persona.py` — единственный владелец файла. `DEFAULTS` = `{outfit 0, background 0,
banter 1, tempo 100, mini true}`; запись без поля читается как дефолт этого поля, а не всего
record'а. Запись идёт через временный файл + `os.replace`, поэтому панель и гейтвей (разные
процессы) не затирают правки друг друга.

## Поля

| Поле | Тип | Диапазон | Что делает на устройстве |
|---|---|---|---|
| `outfit` | int | 0..12 | Костюм Потсика. Таблица `OUTFITS[]` в `potsy.cpp`, `OutfitId::COUNT` = 13. |
| `background` | int | 0..4 | Фон hero-полосы: цифровой дождь, звёздное небо, тостеры, светлячки, чёрный. |
| `banter` | int | 0..2 | Болтовня: 0 молчит, 1 обычная пауза, 2 вдвое чаще (`banterScale`). |
| `tempo` | int | 50..200 | Темп анимации в процентах от задуманного (`Potsy::setTempo`). |
| `mini` | bool | — | Стоит ли мини-Потсик на экране часов в слоте аватара. |

Значения вне диапазона **отвергаются** на записи (`save` → `ValueError`) и **читаются как
дефолт** при чтении (старый или правленый руками файл). Обе стороны нужны: запись не даёт
сохранить то, что прошивка не нарисует, чтение не даёт индексу уехать за таблицу.

## Wire

`adapter._send_persona` отправляет `persona` с `persona_store.wire(record)`:

```json
{"type": "persona", "outfit": 4, "background": 2, "banter": 1, "tempo": 100, "mini": true}
```

Прошивка: `App::h_persona` (`firmware/core/src/app.cpp`) — каждое поле проверяется на тип
(`is_number`/`is_bool`), число обрезается в `potsy_glue::select_*`. Старая прошивка без
`banter`/`tempo`/`mini` просто не увидит этих ключей.

Триггеры отправки: `welcome` (новое подключение), смена профиля на устройстве, и каждый
`PUT /api/plugins/herpots/persona` из панели (через `desk.post_persona` → инбокс → гейтвей).

## Хранение на устройстве

`firmware/core/src/potsy/settings.h` — namespace `Settings`, ключи в NVS через
`Preferences.h` (который поверх `hg::Storage`):

- `bg` — фон (был и раньше, ключ PotsCharm);
- `banter`, `tempo`, `mini` — новые.

`loadKnobs()` читает их один раз при первом обращении; сеттеры пишут сразу. Значение
переживает перезагрузку и работает без связи с Hermes.

## Меню устройства

`Menu::{Banter, Tempo, Mini}` в `include/hg/app.hpp`, обработка в `app_settings.cpp`:
`Banter` перебирает 0→1→2→0, `Tempo` идёт по шагам 60/80/100/120/150/200, `Mini` — тумблер.
Подписи: `i18n_ru.cpp` (Болтовня Потсика / Темп Потсика / Потсик на часах).

## Тесты

`tests/test_persona.py` (корневой плагин, 7 тестов): дефолты на пустом/битом файле,
round-trip всех полей, частичное обновление, значения вне диапазона читаются как дефолт,
`save` отвергает неверные значения и длинные имена профилей, запись одного профиля не трогает
другой.

Отдельный `tests/conftest.py` нужен потому, что `sdk/tests/conftest.py` поднимает
`sdk/plugin` (апстрим-копию), а не корневой `plugin/` — это разные деревья файлов.

```bash
cd /run/media/al/ARCHIVE/code/herpots && /usr/bin/pytest tests -q
```
